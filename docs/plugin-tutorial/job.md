# 职业系统

想在服务器挣金币？来看看怎么使用职业系统  
只能在生存服加入职业，其它子服没有职业系统  
游戏内输入`/jobs browse`或`/jobs join`后，将鼠标指针悬浮在职业方块上查看职业信息

![职业](/images/职业.png)

## 职业介绍界面

左键职业方块查看该职业的具体信息，查看职业信息时，可以通过信息页下方的绿色按钮加入该职业  
在介绍界面，右键职业方块**加入**该职业  

## 如何退出职业

在职业介绍页面，可以按 Q 键退出该职业
或者输入 `/jobs leave [职业名]` 来退出职业

## 收入上限 (每日刷新)

`MoneyLimit: 200+500*(totallevel/100)`
